# ฝึกแคลคูลัสเบื้องต้น — Basic Calculus Practice

เว็บฝึกทำโจทย์แคลคูลัสเบื้องต้น 18 หัวข้อ สุ่มโจทย์ใหม่ได้ไม่จำกัด
ตรวจคำตอบอัตโนมัติ และดูวิธีทำทีละขั้น — **โจทย์และเฉลยแสดงเป็นสมการคณิตศาสตร์จริง**
(เรนเดอร์ด้วย KaTeX) ไม่ใช่ข้อความแบบโค้ด

เข้าสู่ระบบด้วยบัญชี Google ก่อนเล่น บันทึกผู้ใช้ลง Google Sheet
และเก็บคะแนนไว้ใน localStorage — **ไม่มีหลังบ้าน** เป็นไฟล์ static ล้วน

**เว็บจริง:** https://teerach-min.github.io/calculus-practice-web/
(deploy อัตโนมัติทุกครั้งที่ push เข้า `main` ด้วย
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml))

## หน้าเว็บ

| เส้นทาง | หน้า | ต้องล็อกอิน |
|---------|------|-------------|
| `/` | แบบฝึกหัด 18 หัวข้อ สุ่มโจทย์ ตรวจคำตอบ เก็บสถิติ | ✔ |
| `/reference` | สรุปสูตรและนิยาม 9 หัวข้อ พร้อมตัวอย่างจากสไลด์ | — |

หน้าสรุปสูตรเปิดอ่านได้เลยโดยไม่ต้องล็อกอิน เพราะเป็นเนื้อหาเรียนล้วน ๆ
ถ้าอยากให้ต้องล็อกอินด้วย เปลี่ยน `src/app/reference/page.tsx` ให้ห่อด้วย

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:3000
```

ยังไม่ได้ตั้งค่า Google? ไม่เป็นไร — เว็บจะเข้า **โหมดทดลอง** ให้เล่นได้เลย
โดยข้ามหน้าล็อกอิน พอพร้อมค่อยทำตาม [SETUP.md](SETUP.md)

สร้างไฟล์สำหรับ deploy (ได้โฟลเดอร์ `out/`):

```bash
npm run build
```

## วิธีพิมพ์คำตอบ

| ต้องการ | พิมพ์ |
|---------|-------|
| เลขยกกำลัง | `x^2` |
| รากที่สอง | `sqrt(x+9)` |
| เศษส่วน | `5/3` หรือ `(x-1)/(x+2)` |
| อินทิเกรต | ไม่ต้องใส่ `+C` ก็ได้ |
| ลิมิตหาค่าไม่ได้ | `ไม่มีลิมิต` หรือ `DNE` |

ระบบจะแสดง **พรีวิวสมการ** ใต้ช่องกรอกแบบเรียลไทม์ และตรวจคำตอบด้วยการเทียบค่าเชิงตัวเลข
จึงยอมรับคำตอบที่เขียนคนละรูปแต่มีค่าเท่ากัน (เช่น `6x^2-10x+7` กับ `7-10x+6x^2`)
กด **Enter** เพื่อตรวจได้เลย

## การเพิ่มหัวข้อใหม่

เพิ่มฟังก์ชันเข้าไปใน `GENERATORS` ใน `src/lib/generators.ts` และเพิ่มชื่อใน
`TOPIC_LABELS` ให้ตรงลำดับกัน ฟังก์ชันต้องคืนค่าเป็นออบเจกต์ `Problem`
โดยข้อความทุกฟิลด์เขียนเป็นภาษาไทยผสมสูตร LaTeX ครอบด้วย `$...$` (อินไลน์)
หรือ `$$...$$` (แสดงกลางบรรทัด)

## ตรวจสอบอัตโนมัติ

```bash
npm run typecheck        # ตรวจชนิดข้อมูล
npm run test:answers     # เฉลยที่แสดง ต้องผ่านเครื่องตรวจคำตอบ (720 โจทย์)

npm run build
cd out && python3 -m http.server 3100 &
npm run test:render      # เปิดเบราว์เซอร์จริง วนทุกหัวข้อ เช็ค KaTeX + การเก็บคะแนน
npm run test:reference   # ตรวจหน้าสรุปสูตร: 9 หัวข้อ 181 สมการ สารบัญ ลิงก์ข้ามหน้า
```

`test:answers` เอาเฉลยที่นักเรียนเห็น (LaTeX) แปลงกลับเป็นข้อความแล้วป้อนเข้า
เครื่องตรวจคำตอบ — ถ้าผ่าน แปลว่าเฉลยตรงกับสิ่งที่ระบบยอมรับจริง

`test:render` วนทุกหัวข้อ สุ่มโจทย์หลายรอบ เปิดเฉลย ตรวจว่าไม่มี KaTeX error
แล้วทดสอบต่อว่าตอบถูกแล้วคะแนนขึ้น ป้ายในแถบหัวข้ออัปเดต และคะแนนยังอยู่หลังรีโหลด

`test:reference` ตรวจหน้าสรุปสูตร — ครบ 9 หัวข้อ ทุกสมการเรนเดอร์ผ่าน
ไม่มี `$` หลุดออกมาเป็นข้อความ บรรทัดใหม่ระหว่างสมการยังขึ้นบรรทัดจริง
สารบัญไฮไลต์ตามการเลื่อน และไม่ล้นแนวนอนบนจอมือถือ
